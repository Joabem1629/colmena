# Iconos propios para los tableros

Copia aquí tus imágenes (.svg .png .webp .gif .jpg .avif). Aparecen solas en el selector
de iconos del editor, pestaña "Mis iconos". No hace falta reiniciar el servidor.

Nombre del archivo: minúsculas, números y guiones (por ejemplo `mi-logo.png`).
Mejor si son cuadradas, de 64 px o más.

Además, desde el editor se puede subir una imagen (se reduce a 64×64 y se guarda dentro del
tablero). Para quitar ese botón: `ICON_UPLOAD=0` en tu archivo de variables.
